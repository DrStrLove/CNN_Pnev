# CNN_Pnev

Проект по классификации рентгеновских снимков грудной клетки для определения признаков пневмонии.

Модель анализирует изображение рентгеновского снимка и относит его к одному из двух классов:

* Normal
* Pneumonia

## Что делает проект

Проект решает задачу бинарной классификации медицинских изображений.

На вход подаётся рентгеновский снимок грудной клетки.
На выходе модель предсказывает, есть ли на снимке признаки пневмонии.

```text
Chest X-Ray image → CNN model → Normal / Pneumonia
```

## Основная идея

Для решения задачи используется сверточная нейронная сеть.

CNN хорошо подходит для работы с изображениями, так как может выделять визуальные признаки: контуры, текстуры, локальные паттерны и более сложные структуры.

В рамках проекта были выполнены:

1. Загрузка и анализ изображений
2. Предобработка данных
3. Нормализация изображений
4. Подготовка train / validation / test выборок
5. Построение CNN-модели
6. Обучение модели
7. Оценка качества классификации

## Данные

В проекте использовался датасет рентгеновских снимков грудной клетки, разделённый на два класса:

* `NORMAL`
* `PNEUMONIA`

Примерная структура данных:

```text
data/
│
├── train/
│   ├── NORMAL/
│   └── PNEUMONIA/
│
├── val/
│   ├── NORMAL/
│   └── PNEUMONIA/
│
└── test/
    ├── NORMAL/
    └── PNEUMONIA/
```

## Модель

В проекте использовалась CNN-модель для классификации изображений.

Общая схема модели:

```text
Input image
    ↓
Convolutional layers
    ↓
Pooling layers
    ↓
Dense layers
    ↓
Output: Normal / Pneumonia
```

## Метрики

Для оценки модели использовались стандартные метрики классификации:

* Accuracy
* Precision
* Recall
* F1-score
* Confusion Matrix

Особое внимание уделялось снижению количества false negative ошибок, так как в медицинской задаче важно минимизировать случаи, когда модель пропускает признаки заболевания.

## Результат

Итоговая модель достигла качества около:

```text
Accuracy: ~90%
```

Также модель показала низкую долю false negative ошибок на тестовой выборке.

## Как запустить

### 1. Клонировать репозиторий

```bash
git clone https://github.com/DrStrLove/CNN_Pnev.git
cd CNN_Pnev
```

### 2. Установить зависимости

```bash
pip install -r requirements.txt
```

### 3. Запустить notebook

```bash
jupyter notebook CNN_Pnev.ipynb
```

или:

```bash
jupyter lab
```
